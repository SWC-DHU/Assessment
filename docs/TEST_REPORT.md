## 真实工作簿

人工标注 `backend/experiments/battery_module_gold.json` 来自 `Sheet1` 的 A:H 列。离线方法 C 三次独立运行都匹配 16 道工序、29 种物料和 58 条范围内关系。关系范围为直接前驱、消耗、产出。词表小样中的 8 个能力条目全部映射正确，逐字引文和位置可复核。三次内容摘要一致，模型请求数为 0，Token 无数据。

原表没有设备型号、单件工时、明确的产品组成或整线定量约束。测试从指定版本对第三道工序 `03 贴胶` 添加 45 秒工时，新约束引用本次用户消息，既有工序、物料及工艺流向保留。预览和 Excel 均显示 45，原版本的工时仍为空。其他空值单元格按来源或映射状态解释。
