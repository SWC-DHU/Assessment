# 3D Geometry Binding Directory (Reserved)

This directory is reserved for future 3D CAD / mesh files (`.glb`, `.gltf`, `.step`, `.usd`, etc.).

Model semantic definitions under `../data/*.json` are decoupled from 3D files and bind via stable `identity.asset_id` (`model_binding.asset_ref_key`) and `model_binding.model_uri` (e.g. `geometry/MA-FEED-01.glb`).
